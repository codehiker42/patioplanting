## Patio Planting, A C++ library for linear algebra and machine learning

Patio Planting is a C++ 23 library for linear algebra, data processing, and machine learning. It aims to be a single tool that combines [NumPy](https://numpy.org/), [R DataFrame](https://www.rdocumentation.org/packages/base/versions/3.6.2/topics/data.frame) or [Pandas](https://pandas.pydata.org/), [scikit-learn](https://scikit-learn.org/stable/index.html), and [PyTorch](https://pytorch.org/). Unlike many scientific and mathematical tools, Patio Planting statically types all data types and operations by using C++ templates. It provides tailored execution for a specific environment and data, at the cost of compilation.
